# 🧠 DSA em Java

Olá! 👋 Este repositório documenta minha prática contínua de **lógica de programação, algoritmos e estrutura de dados (DSA)**, resolvendo desafios do [Beecrowd](https://www.beecrowd.com.br/) em **Java**.

O objetivo não é só acumular soluções — é treinar raciocínio antes de sintaxe, sem depender de IA nesse processo. Cada arquivo aqui foi pensado e escrito por mim, do zero.

**Perfil Beecrowd:** [luanbrgs1](https://judge.beecrowd.com/pt/profile/1167752)

---

## 📁 Estrutura

Organizado pelas categorias oficiais do Beecrowd, criadas conforme resolvo os primeiros problemas de cada uma — sem pasta vazia adiantada:

- `1-iniciante/`
- `2-ad-hoc/`
- `3-strings/`
- `4-estruturas-e-bibliotecas/`
- `5-matematica/`
- `6-paradigmas/`
- `7-grafos/`
- `8-geometria-computacional/`

Cada arquivo segue o padrão, que vai ser o numero do problema da pasta em`` (ex: `1001-extremamente-basico.java`).
